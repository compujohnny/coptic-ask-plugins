# Ask the Church Fathers — اسأل آباء الكنيسة

Ask the Church Fathers (اسأل آباء الكنيسة): your Bible and spiritual questions answered with clips of recorded sermons and lectures by Coptic Orthodox fathers and teachers, as in the CopticBible app: video and audio parts with exact time ranges, Bible references, Arabic captions, English subtitles and dub where available, and links to the web and the Android app.

Every answer is made of real recordings: the service picks the parts of the lectures that answer your question and
plays only those parts. Nothing is generated. Each part shows its heading, the speaker and lecture, Bible references,
a summary, what is said (Arabic captions; English subtitles and an English dub for translated parts), and a link that
plays it at the exact time. Each answer links to the same answer on our website and in the Android app
(`com.compujohnny.copticbible`).

## Install

- Claude Code: `/plugin install ask-church-fathers --marketplace compujohnny/coptic-ask-plugins`
- Codex: `codex plugin marketplace add compujohnny/coptic-ask-plugins`, then `codex plugin add ask-church-fathers@coptic-ask`

## Use

- Claude Code: `/ask-church-fathers:ask <question>`, or just ask a question (the skill calls the tools).
- Codex: ask a question; the `ask-church-fathers` skill uses the `ask-church-fathers` tools.

Tools: `ask`, `get_answer`, `get_part`, `search` (free outline search), `list_sources` (sources and today's questions).
How agents must show answers: `skills/ask-church-fathers/references/RENDERING.md`.

## Privacy

The question you ask is sent to our service to find the answer and is kept with the answer so the answer link works.
No account, name or other personal data is collected. Privacy policy: https://compujohnny.com/ask-the-church-fathers/privacy/ · Terms: https://compujohnny.com/ask-the-church-fathers/terms/
