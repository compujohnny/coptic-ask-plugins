# Ask Pope Shenouda — اسأل البابا شنوده

Ask Pope Shenouda III (اسأل البابا شنوده): your spiritual and Bible questions answered with clips of his own recorded lectures, as in the Pope Shenouda app: video and audio parts with exact time ranges, Arabic captions, English subtitles and dub where available, and links to open the answer on the web and in the Android app.

Every answer is made of real recordings: the service picks the parts of the lectures that answer your question and
plays only those parts. Nothing is generated. Each part shows its heading, the speaker and lecture, Bible references,
a summary, what is said (Arabic captions; English subtitles and an English dub for translated parts), and a link that
plays it at the exact time. Each answer links to the same answer on our website and in the Android app
(`com.compujohnny.popeshenouda`).

## Install

- Claude Code: `/plugin install ask-pope-shenouda --marketplace compujohnny/coptic-ask-plugins`
- Codex: `codex plugin marketplace add compujohnny/coptic-ask-plugins`, then `codex plugin add ask-pope-shenouda@coptic-ask`

## Use

- Claude Code: `/ask-pope-shenouda:ask <question>`, or just ask a question (the skill calls the tools).
- Codex: ask a question; the `ask-pope-shenouda` skill uses the `ask-pope-shenouda` tools.

Tools: `ask`, `get_answer`, `get_part`, `search` (free outline search), `list_sources` (sources and today's questions).
How agents must show answers: `skills/ask-pope-shenouda/references/RENDERING.md`.

## Privacy

The question you ask is sent to our service to find the answer and is kept with the answer so the answer link works.
No account, name or other personal data is collected. Privacy policy: https://compujohnny.com/pope-shenouda/privacy/ · Terms: https://compujohnny.com/pope-shenouda/terms/
